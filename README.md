# proyectofutbol
Aplicación web de fútbol desarrollada con DATAFLEX.

# descripción
FutbolWebApp es un proyecto desarrollado para trabajar con las tecnologías web y herramientas de desarrollo DATAFLEX

# tecnologías
DataFlex: entorno de desarrollo de la aplicación
Git: control de versiones.
GitHub: alojamiento y gestión del código fuente.

# estructura del proyecto
AppHtml/: recursos relacionados con la interfaz web
AppSrc/: código fuente de la aplicación
DDsrc/: definiciones relacionadas con los datos
Data/: archivos de datos del proyecto
IDesrc/: archivos del entorno de desarrollo
Programs/: programas y componentes de la aplicación
FutbolWebApp.sws: archivo de solución del proyecto
